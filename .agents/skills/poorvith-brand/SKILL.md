# Poorvith Brand

Always follow the brand reference in `references/design.md` for Poorvith customer-facing work.

Core rules:
- Preserve the brand as-is. Do not rename, recolor, or replace the identity unless Poorvith explicitly asks.
- Use the defined typography, color palette, glass surfaces, and hierarchy from the reference.
- Apply color psychology inside the existing palette: emerald for trust/action/success, amber for attention/warnings/locked states, red only for risk/destructive actions, blue/purple for technical/code signals, slate for calm structure and readability.
- Keep customer attraction grounded in clarity, confidence, conversion flow, and premium execution rather than loud generic decoration.

Read `references/design.md` before making brand, marketing, UI, or visual decisions for Poorvith projects.
